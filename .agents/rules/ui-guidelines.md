# UI and Content Guidelines

## Emojis
- **DO NOT** use emojis anywhere in the application, neither in the UI (React components) nor in the AI's responses (system prompts).
- If you need a visual indicator, use vector icons (e.g., from `lucide-react`) that match the existing app styling.

## App Styling
- Maintain a consistent, modern, clean look. 
- Use the established CSS variables (e.g., `var(--primary)`, `var(--text-main)`, `var(--card-shadow)`).
- Ensure fonts match the app's default font family.
